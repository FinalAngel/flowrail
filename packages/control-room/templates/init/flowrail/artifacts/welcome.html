Artifact

Agents leave reports here

An artifact is one self-contained HTML file in flowrail/artifacts/. Routines and agents write them; you read them on the dashboard. They open in a sandbox, so a report can show charts and tables but cannot call the flowrail API or read your files.

  1. Ask Claude for a report: "Summarize this week's commits as an HTML artifact in flowrail/artifacts/".
  2. Add a sidecar name.json with title, summary and tags if you want a nicer card.
  3. Delete from the dashboard moves the file to .flowrail/trash/. Nothing is ever removed for good.

This page is a starter file. Move it to the trash once you have a real report.
