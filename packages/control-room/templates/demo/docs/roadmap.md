# Roadmap

What we plan to ship, in order. Dates are targets, not promises.

## 0.9: Sync you can trust

- Paragraph-level merge for offline edits on two devices
- A conflict view that shows both versions side by side
- Search index that updates incrementally instead of on every keystroke

## 0.10: Your notes, anywhere

- Export all notes as a zip
- Import from a folder of plain text files
- Mobile layout for the note list

## Later

- Encryption at rest, with the key kept in the system keychain
- Tag suggestions from note content
- A plugin API for custom renderers

## Not planned

- A hosted cloud. Sync stays peer to peer or through a folder you choose.
- Real-time collaborative editing. Paper Plane is a personal notebook.

See [architecture](architecture.md) for how sync works today, and [[sync-merges-per-paragraph]] for the reasoning.
