# Release checklist

The short version. The full procedure with the sign-off gate is `flowrail/workflows/release.md`.

- [ ] All tasks for the release are Done on the board
- [ ] CHANGELOG has an entry for every user-visible change
- [ ] `npm test` passes on a clean checkout
- [ ] Version bumped in `package.json`
- [ ] Human sign-off on the release notes
- [ ] Tag pushed and package published by a human
