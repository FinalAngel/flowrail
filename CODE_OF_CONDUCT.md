# Code of conduct

flowrail follows the [Contributor Covenant, version 2.1](https://www.contributor-covenant.org/version/2/1/code_of_conduct/). In short: be considerate, assume good faith, criticize ideas rather than people, and leave room for people who are new.

It applies in issues, pull requests, discussions and anywhere else you represent the project.

To report a problem, contact the maintainers privately through the email address on the repository owner's GitHub profile, or through a private security advisory if nothing else is available. Reports are handled in confidence. Maintainers may remove comments, lock threads, or ban participants who break the code of conduct, as described in the Covenant's enforcement guidelines.
